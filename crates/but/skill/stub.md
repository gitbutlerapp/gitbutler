# GitButler CLI Skill

Before your first `but` or git write command, run this on its own and read all of it:

```bash
but skill
```

It prints the usage guide (about 160 lines) from the installed CLI, so the guide always matches the version on this machine. This file holds no guidance of its own: nothing here says how to commit, uncommit, amend, recover, or update, and searching it answers no such question. Run the guide alone; other commands in the same call get buried under it.

The guide covers the loop, IDs, rules, and task recipes. When you need a flag it does not mention, `but skill reference` prints each command's syntax and flags.

Follow the guide's applicable recipes and stopping rules.
