# Design notes

The rules for every GitButler app, on any platform, are `@gitbutler/but-ui`'s
design notes: [its DESIGN.md](../but-ui/DESIGN.md) and the pages in its
`design/`. What's here is only about building with `@gitbutler/but-ui-react`;
the tooling that enforces the rules lives in `AGENTS.md` beside this file.
